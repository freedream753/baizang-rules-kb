# 一、击杀类

### 击杀队友（TK）的正当理由（4.1）

击杀队友（TK）指在没有正当理由的情况下杀害队友；间接导致盟友死亡同样适用（如被 SCP-409 感染，有义务让队友知道）。
正当理由【封闭名单】：
1. 进入交火线
2. 信息差
3. 自卫反击
4. 合理命令击杀
5. 死亡威胁
6. 暴露队友
7. 多次或在警告之后继续扰乱阵营行动
8. 积极协助敌人
9. 穿戴不符合阵营的服饰
10. 在被感染蓝冰或着火的情况下持续靠近队友
11. 此人开始杀害你的队友
名单之外的理由击杀队友按 TK 处理，具体处罚查《13-处罚速查》。

### 开枪会打到前面的队友——普通武器交火线（4.2-1）

使用武器射击时不应无视你前方的队友。以下三种情形开枪不算违规【封闭名单】：
1. 队友与手持武器的中立、敌方、SCP 单位处于同一枪线上（SCP-999-2 除外）
2. 队友在你开枪时从你的视角以外进入枪线，你来不及反应
3. 你已经及时警告过不要阻挡你的枪线（此条适用"发出命令"规则）
证据要求：交火线情形最好需要录屏为证。

### 范围性武器伤到队友（4.2-2）

范围性武器原文列举：SCP-009、SCP-409、各种果汁、即刻放置的 CI 诡雷、电磁炮、燃烧弹、RPG、自爆装置（原文注明"包括但不限于"）。
处罚口径（4.2-2 明文）：使用范围性武器直接导致多名队友死亡或被感染的，从第 3 名举报人开始计入一次 TK，之后每多一人则多计算一次 TK。
以下三种情形开火不算违规【封闭名单】：
1. 队友已经明显无生还可能
2. 你及时警告过队友远离
3. 队友在你开火后主动进入范围

### 队友打了友军能不能杀他——信息差（4.3）

1. 当你在同一空间目睹你明面上的队友去攻击你的友军，可以以损害同阵营利益行为为由击毙该攻击者，或按指挥阶级命令叫停询问当时情况
2. 敌人以欺骗手段促使他人 TK 你：TK 你的人不负责任
3. 队友以欺骗手段促使他人 TK 你：击杀的人与队友负违规责任
4. 利用广播的欺骗同样有效；杀人方发现被骗 TK 后可以击毙怂恿方

### 被人开火了能不能反击——自卫反击（4.4）

判定：当有人明显向你开火，你可以立即反击他；反击仅限对方正在攻击或刚完成攻击的情况下，此时不产生任何责任。
禁止仇杀：出于对方刚才误伤了你、在明显你们为队友的情况下跑去杀了他——此时按击杀队友（TK）处理。

### 不听命令能不能直接击毙——合理命令击杀（4.5）

基金会武装单位以下命令，不服从可以直接击毙【封闭名单】：
1. 命令同级及下级单位人员不允许靠近自己 / 枪口不许指向自己
2. 命令下级单位人员把武器收起来
3. 命令下级单位人员停下或接受检查身份
时限：发出命令 / 警告 / 不配合等情况超过 5 秒后可开枪直接击毙，不承担 TK 后果。
命令本身是否有效（是否属于不合理命令）查本文件《哪些命令不合理、必须不听（3.4）》。

### 什么情况算无理由击杀（RDM）（4.6）

无理由击杀（RDM）指在没有正当理由下杀死伪装成同阵营的敌人 / 中立角色。
原文实例【封闭名单】：
1. 此人拒绝提供 ID 卡
2. 此人提供的 ID 卡与他们的外表不符
3. 此人开始杀害你的队友
4. 此人拒绝在非轻收容净化情况中脱下防化服
5. 此人持枪与其敌对的持枪人员同行

### 被电击器电了能不能杀对方（4.7）

1. 安保部门人员开局时如果有人使用电击器电击你，在你做出"不要电击你"的警告后他仍然电击你，你有权击杀他；此时知情单位击杀你算 TK / RDM
2. 其他条件下电击他人算作攻击行为：有人无理由电击你，你可以击毙该玩家（保安拿到子弹后适用此规则）

### 看人物模型 / 行为能不能直接杀（4.8）

1. MTF 士兵背大背包或挎肩包：该玩家设为未知人员，基金会武装单位有权命令对方脱下衣服查验身份
2. D 级人员-运动员穿着科研 / 医生衣服 / 防护服：观察发现甩手手臂动作不合理，可推断为 D 级人员，允许击杀
3. 运动员、黑客、杀手等若未被道德伦理检察官转化为科研人员，发现该玩家使用技能或道具，可判定为 D 级人员，不需要查验可以直接击毙
4. 开局发现特殊人物角色语音说话声音不一样（例：内部安全代理、上尉等角色）、已确认该角色死亡无法复活、人物模型面部有伤疤模型错误、MTF 人员武装佩戴防毒面具模型出现错误时，有权直接击毙
5. 通过动作与尸体突然被吃与特殊模型击杀了穿着防化服的运动员：杀对了不算猜杀，杀错了算作 TK（不是 RDM）
6. 可被视作绝对基金会阵营的科研单位【封闭名单】：胖 / 壮科研人员、人事主管、特殊科研、女清洁工。命令以上人员出示 ID 卡、丢出武器会被视作不合理命令

### 靠推理杀人算不算正当——推理击杀（4.9）

仅允许下述情况根据已有信息推理击杀他人，但 TK 仍可能导致惩罚：
一、身份推理：
1. 你目睹到安保与持武器 D 级人员同行，可以怀疑他是混沌分裂者间谍或伪装的 D 级人员并杀死他
2. 有人做出明显的攻击意图时你可以杀死他（如某人明显向你开枪）
二、场景推理：
1. 密闭空间（仅有一个出入口的房间）内存在尸体与仅有一个可能的凶手；尸体死亡时间为最近死亡；你有合理的理由
2. 你通过面板确认人数
三、语言推理：
1. 某人当面宣称他为你的敌对势力（包括暗示、代号）你可以击杀他
2. 你看到表面上的友军与敌对阵营有合作沟通

# 二、撤离类

### 紧急疏散开始后要做什么（5.1）

紧急疏散开始，所有阵营（除 UIU 特工组）判为任务失败，首要目标更改为逃离设施；撤离途中可以忽视敌对阵营。
以下行为可能被视作堵撤离点 / 能撤不撤【管理裁量】：具有撤离条件但无撤离意愿；主动杀人具有主观恶性。
时间段：播报紧急疏散提示 → 阿尔法核弹启动中 → 阿尔法核弹启动。
特殊事件-流星：该事件发生时回合进度条（右上角）变为黄色，紧急疏散提前触发，此时遵循紧急疏散规则。

### 去别的阵营撤离点杀人——堵撤离点 7 情形（5.1）

在阿尔法核弹启动前可以前往其他阵营撤离点击杀准备撤离的人，但以下 7 种情形视作 OOC【封闭名单】：
1. 前往其他阵营撤离点杀人且最终死亡的
2. 非军事人员堵蛇之手传送门撤离点最后死亡的
3. 伪装人员在未明确受到生命威胁的情况下，在非该阵营撤离点喝自爆饮料将其他玩家全部炸死的
4. 伪装、间谍人员在直升机、装甲车处杀人并且原地撤离的
5. 有能力完成任务时不完成，而拖时间到紧急疏散去堵撤离点的
6. 紧急疏散开始时强迫他人履行与撤离无关的命令的
7. GOC 间谍在未穿戴装甲的情况下拦截撤离点的

### 有条件撤离却不走——能撤不撤（5.1）

1. 在阿尔法核弹开启后，所有人应当立即前往撤离点撤离；在撤离点外有杀人且当场死亡或最后被核弹炸死的，将酌情判处能撤不撤【管理裁量】
2. SCP 若被辱骂、嘲讽等，应采取举报途径，而非以能撤不撤的方式堵死他人
不算能撤不撤【封闭名单】：在前往撤离点路上的途中遇敌杀人的；受到威胁必须杀人的；杀人时明显无条件撤离的等无恶意死堵他人的情形。

### 堵撤离点 / 能撤不撤的例外（5.1）

以下 8 条为堵撤离点与能撤不撤规则的例外【封闭名单】：
1. 军事人员允许随意堵蛇之手传送门撤离点
2. 处于撤离点的人员优先开火攻击路过人员，路过人员开火还击不算堵撤离点
3. 基金会阵营人员在直升机被摧毁后，可以选择堵 CI 撤离点
4. D 级人员允许在装甲车被摧毁的情况下拦截基金会（D 级人员穿戴伪装衣服不可在飞机杀人，可直接从飞机撤离）
5. GOC 阵营 / 穿戴装备后无时间完成任务的 GOC 间谍 / 猩红王之子 / 在紧急撤离前未能完成任务者，无堵撤离点与能撤不撤规则
6. CI 混沌分裂者在九尾狐直升机未摧毁情况下，允许蹲守基金会停机坪，摧毁直升机阻止基金会阵营撤离
7. 火车撤离点仅只有基金会阵营可以撤离；拦截火车导致自身撤离失败列为能撤不撤
8. 拦截通用撤离点导致撤离失败列为能撤不撤

### 和敌人一起撤离——合作撤离（2.2）

禁止和敌对阵营合作撤离。
处罚（2.2 明文数值）：ban 24 小时 + 扣除 1 级，详见《13-处罚速查》。

# 三、阻挡类

### 堵门 5 秒怎么算（2.7）

1. 禁止用身体阻挡玩家前进累计超过 5 秒，从停止移动时起算（包括使用电击器电击对方导致堵门 5 秒）
2. 例外：允许以击杀人类为目的阻挡，或帮助队友击杀人类而堵门，必须在 5 秒内击毙被堵门的人类
3. SCP 阵营因无法击杀玩家用身体阻挡玩家累积超过 10 秒算违规，从被堵人员因被堵而停止或移动时起算（不包含 SCP-096 狂暴准备进入攻击阶段）
4. 堵门者被被堵门者电击时计时暂停
5. 盾牌持有者可随意阻挡非友军单位
6. 例外：特科 Shieldmeh 开启立场护盾期间不视为持有盾牌，堵门最多仅可堵 5 秒
举报要求：恶意阻挡举报需附虚拟 ID。

### 用电梯门杀人（2.7）

除盾牌持有者，其他人禁止通过恶意堵门的方式用电梯门击杀无威胁目标。

### 蹲出生点杀人（2.9）

禁止所有阵营提前破门或蹲守进入以下出生复活点等待支援部队刷新、在未读完复活动画时进行杀人【封闭名单】：QRT、XI-8、Alpha-9、Nu-7、UIU、24TH、GRU-P、UIU 拦截者（包含吃冰后进入复活点导致的感染）。
另：禁止其他阵营提前蹲守 Alpha-9 出生点停机坪、GRU-P 出生点平台拦截，必须等待其离开出生点保护范围才允许先手攻击（原文标注"实装掩体后删除"，现行有效）。
出生点判定图示在原文档中仅有标注名称、无文字说明具体范围，无法引用图片判定范围【管理裁量】。
处罚口径：规则只写"禁止"未给数值，归 OOC 体系由管理裁量，见《13-处罚速查》。

### D 级人员关押保护区（2.10）

1. 安保部门和科研部门：禁止在 D 级人员关押区查区威胁 D 级人员
2. MTF 基金会武装部门：允许进入 D 级人员关押区进行巡查，但不能击杀关押区内的 D 级人员
3. MTF 击杀关押区内 D 级人员的例外【封闭名单】：D 级人员持有武器；关押区内有基金会人员尸体；言语调戏

# 四、命令类

### 广播命令的效力（3.1）

1. 广播室的命令为最高优先级，默认由本局基金会最高指挥单位发布。违反命令不会算作 OOC，但其他人有权处决你
2. 广播室的命令无需明确目标是否已接收到命令，发出命令后默认所有人已经收到，违令即可以处决（如：防护服禁止持枪 = 持枪直接击毙；以对讲机关闭没收到命令为理由属于无效辩解）
3. 语音广播禁止放音频语音包，禁止辱骂嘲讽玩家等行为
4. 若使用广播室语音发布基金会命令，发布前应先文字发布一遍，否则视为无效命令

### 现场命令与 5 秒反应时间（3.2）

1. 现场发出的口头命令或文字命令，必须要求目标能接收到这个命令，并应当给予 5 秒反应时间；查验身份时如出现逃跑、躲藏或多余动作（如捡枪）允许直接击毙
2. 在突发危险的紧急情况下（如你正被 SCP 追逐或 SCP 突然出现）下达查验身份等不能立即响应的命令，属于无效命令
3. 违令定义：某人在接收到命令后拒绝履行或拒绝完全履行命令
4. 处决违令者时请确保周围人认可他有违令行为，否则你的队友可能有权击杀你（不允许不承认发生在你面前的违令行为；使用欺骗手段击杀他人时同样有效）
5. 指挥官命令队员：经一次当面警告后若其继续违抗命令，可以在 10 秒内处决他；若他逃离指挥、脱离队伍，当你们汇合时需再次警告其服从命令

### 读秒过快击杀（3.3）

如果你死亡的根本原因不是因为读秒过快（5 秒），那么杀害你的人不承担责任。
若死因涉及未给足 5 秒反应时间，责任按本文件《现场命令与 5 秒反应时间（3.2）》判定。

### 哪些命令不合理、必须不听（3.4）

以下命令属于不合理命令【封闭名单】，命令不生效：
1. 强制他人穿戴防化服
2. 禁止特殊科学家和人事主管携带武器（例外：特殊科学家 / 人事主管积极协助 D 级人员除外）
3. 命令人员丢弃 SAFE 级的 SCP 对象（不包括 SCP-215；如果你被 SCP-409 感染可以索要 SCP-500 解除感染）
4. 禁止科研人员使用额外方法逃生（汽车、断手、O5 撤离点）
5. 让医生身份的玩家出示除颤器来辨别身份
6. 让科研人员穿戴防护服辨认身份
7. 在 MTF 士兵服装人员出示军事 ID 卡的情况下，以他没有武器为由击杀
8. 安保在开局时命令门口的菜鸟或者警卫去后面排队
9. 基金会武装单位在办公区、地表限制科研人员行动（可命令不准靠近自己）
10. 向医疗单位强行索取除颤仪
11. 在轻收区放毒收容时命令对方脱下防护服（以最后 30 秒语音广播为界限）
12. 混沌分裂者阵营命令限制 D 级人员自由行动
13. 在广播中下达禁止科研 / 防化服持有近战武器和 SCP-409 此类命令
14. 人事主管在发布快捷命令后，其他人员理应知道此人是人事主管
15. 指挥官发布其他不符合阵营作战命令与损害利益的作战命令
不合理命令本身不生效、不处罚执行异议者；具体口径查《13-处罚速查》。

### 哪些命令合理、必须执行（3.5）

以下命令有效【封闭名单】：
1. 基金会武装单位在任何情况下可命令科研助手 / 医生 / 研究人员 / 高级研究员 / 男清洁工 / 男道德伦理检察官丢掉武器和不持有武器
2. 基金会武装单位命令下级单位索要或交出以下 SCP 物品是有效命令：SCP-008、SCP-009、SCP-018、SCP-215、SCP-409、SCP-3238 自爆果汁、SCP-3238 辐射果汁
3. 基金会人员可命令同级及下级单位人员不允许靠近自己 / 枪口不许指向自己
4. 基金会人员可命令下级单位人员把武器收起来 / 丢掉非出生自带的武器
5. 基金会武装单位可命令下级单位人员停下或者接受检查身份

### 看到防化服怎么判定身份（3.6）

1. 防化服与 D 级人员 / 混沌分裂者同行：默认 D 级人员；防化服与基金会人员同行：默认为科研；防化服单独或集群：默认为未知，需命其脱去防化服验证身份，直接击杀视为 RDM
2. 基金会军事人员：发现其与持枪 D 级或敌人同行时视作敌人，其余情况需查明身份
3. 未着防化服的科研人员：发现与持枪 D 级同行时视作敌人；你没有权力查验防化服
4. 穿防化服的科研人员：始终需要探明其他防化服身份；你没有权力查验防化服

# 五、其他行为

### 角色扮演准则（OOC）与间谍规则（2.1）

1. 禁止违反你的角色规则；角色规则包括其任务、关系以及与其他阵营的互动
2. 禁止不执行 / 忽视为该角色分配的任务，做不利于你与盟友共同目标的行为（如无另外提及或特殊情况，敌对阵营应互相攻击，友方阵营不应无理由或多次攻击）
间谍通用规则：
1. 主动为死亡暴露自己身份视为 OOC
2. 时刻隐藏自己的身份
3. 禁止间谍（不包括混沌分裂者间谍）在自己或队友没有死亡威胁、任务未完成时，除掩护队友外的情况下使用 SCP-009、自爆饮料、SCP-008 发动自杀式袭击
4. 间谍在为保护自己和实现更大利益时可以与其他阵营合作

### 损害同阵营利益（2.3）

1. 禁止在无正当理由的情况下，以作为或者不作为损害同阵营利益
2. 禁止在有正当理由的情况下，以作为或者不作为损害大于等于两人以上的同阵营利益（例：为了躲避 SCP 追击随手关门导致两名队友死亡）
3. 禁止未受到威胁 / 故意 / 自愿大规模加入 SCP-049-2

### SCP-409 相关行为（2.4）

1. 禁止任何阵营在无防护的情况下触摸 SCP-409；如果你在紧急情况下使用了 SCP-409，必须确保你最终不会死于它（你的尸体传染几个算几个警告）
2. 若 D 级人员-小偷在偷取到别人的 SCP-409，禁止在无防护服情况下使用 SCP-409 击杀任何阵营
3. 禁止自己感染 SCP-409 依然选择靠近友方阵营（有义务对友军进行声明自己已经感染 409）
处罚口径（2.4-1 明文）：无防护使用致他人感染或死亡，尸体传染几人算几个警告，见《13-处罚速查》。

### SCP-035 佩戴与击杀（2.5）

1. 禁止基金会武装人员长时间蹲守 SCP-035 收容间
2. 初始 SCP-035 只有蛇之手阵营、D 级人员可以主动寻找佩戴并转化 SCP 阵营
3. 发现掉落的 SCP-035：科研部门、D 级人员、蛇之手可以捡取佩戴；其余阵营均不可佩戴并转化为 SCP-035
4. 当你看到你的友军进入 SCP-035 收容室，此人视为已被蛊惑洗脑，允许直接击杀
5. 只有在 SCP-035 收容室外的 SCP-035 才能被视为掉落的 SCP-035
6. 掉落的含义：他人戴上后被击杀（全局广播提示）

### 特殊事件时该做什么（2.6）

优先级：仪式 = 欲肉 > 核弹。
1. 欲肉教会仪式第一阶段：其他阵营继续执行自身任务；基金会武装单位应搜寻地点做出反应
2. 欲肉教会仪式第二阶段（大标提示）：所有武装单位（GRU-P 除外）必须前往关闭仪式
3. 阿尔法核弹和猩红之子召唤仪式同时开启时，应更积极处理猩红之子召唤仪式（你离谁近先处理谁）
4. 阿尔法核弹非法启动时，设施内基金会武装单位应竭尽全力关闭
5. 核弹、仪式 / 欲肉开启时，地表驻守武装单位不持有下达设施的条件（无权限卡）应当驻守通用撤离点直到最后 30 秒
6. 核弹开启时所有未知单位可以撤离设施；UIU 特工组 / GOC 不允许撤离设施，应当继续执行任务；蛇之手必须营救一个 SCP 才能撤离设施
7. 仪式 / 欲肉仪式第二阶段（大标提示）开启时，所有未知单位不可撤离设施（GRU-P 除外）
8. 间谍单位在特殊事件发生时（不包含羔羊、GOC 间谍）若拥有撤离设施的条件，允许撤离设施
各阵营在特殊事件中的职责分工查《11-特殊事件速查》。

### 鞭尸与记 ID（2.8）

鞭尸：
1. 禁止使用除颤器将人救起来后立马击杀
2. 禁止恶意使用武器攻击尸体
记 ID：
1. 如果你在游戏中看见有非同阵营玩家穿戴伪装服饰并记住他的游戏名字，你或你让其他人击杀他必须带有录像或者截图来证明，否则你可能因"RDM"被处罚
2. 若你记住了所有 MTF 的 ID，当你让穿戴 MTF 制服的人脱下衣服时必须声明，并带有录屏或截图来证明（可以截图往群里发，再进行声明）

### 对讲机频道（2.8）

1. 所有武装人员应当保持对讲机常开（默认按 G）
2. 对讲机频道内只有指挥阶级人员及分支阵营作战核心播报的信息才拥有决策权（例：你知道游戏内名为 FUCK YOU 的玩家为安全主管——若被举报需提供视频证明，需要见到本人——但不知道设施主管叫什么；若对讲机频道内自称设施主管的人发布了其他冲突信息，只有 FUCK YOU 发布的信息你才有理由相信）
3. 若决策权人员与其他决策权人员播报信息冲突，默认优先听取官阶最高、本分支阵营指挥官的播报信息
4. 若指挥官人员播报的信息误导作战人员（TK 等），责任由指挥官人员承担
5. 作战人员（非指挥官及作战核心）发布的信息仅可作为参考，不可作为有效信息

### 死亡记忆（2.11）

1. 禁止支援单位利用复活前记忆知晓对讲机频道或活人身份和位置并前往击杀（例外：阵营简报汇报设施并非死亡记忆；若被举报请提供视频证明）
2. 禁止战局内角色在死亡的时候以不正当手段获取信息并在复活后加以利用（如：死亡的时候利用观察者视角寻找敌人信息，被除颤器复活后前往击杀、报点等）
3. 除基金会友军阵营以外，禁止第一波支援之后刷新的支援和召唤部署的部队从 D 电梯下达前往避难所（需权限卡开门内的房间，不包含电梯外）
4. 换路定义：支援单位下达设施时发现设施人员阻碍无法进入，可以选择换路前往其他通道下达设施；在地表区域遭遇其他敌对目标不能直接开火攻击，如遇对方开火攻击允许反击击毙，你的目的仍是尽快下达设施完成你的任务

### 利用 BUG（2.12）

1. 禁止故意利用游戏模式 / 服务器 / 地图错误来获得优势
2. 若卡 BUG 不清楚情况请举报联系服务器管理员询问，严禁已知或利用服务器 BUG 游玩干扰对局行为
原文列举的漏洞滥用情形（部分，原文未声明为封闭名单）：
1. 使用恶意 BUG（无限 SCP-008 / SCP-009 跑打）
2. 在玩家已有进度条时使用身体或物体卡住衣服，使其不可以拿起并且装备衣服
3. 将其他衣服或护甲脱在衣服上，使人不能第一时间拿起并装备衣服
4. 将物品扔进门口导致门被卡住
5. 卡入自动售卖机
6. SCP-076 或其他 SCP 故意击杀或使用技能穿地图模型杀人（例：除 AOE 伤害）
7. 玩家恶意卡设施地表地图 BUG 区域去杀人或完成任务
8. SCP-811 和 CI 混沌分裂者-伏击者卡地图模型布置地雷
9. 通过踩书 / 交互的行为判断猩红祈祷地点 / GOC 装甲
10. 通过丢下后捡起的方式消除电磁炮的开火前摇
11. 通过其他方式来模拟快捷指令（包含内部安全代理）
12. 在玩家 035 转变期间将其杀死后复活
