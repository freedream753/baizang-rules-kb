# 08 人物图鉴 · 总览

> 数据来源：`白藏服务器人物介绍.docx`（游戏内按 F2 查看，需达到对应游玩等级才能解锁）。
> 版本：2026/10/23（人物文档改动日志最新条目，见文末）。

## 定位与边界（先读这段）

1. 本图鉴只回答三件事：**这个角色叫什么、属于哪个阵营、有什么特性**（伪装能力、查验能力、招募能力、携带物、技能）。
2. 本图鉴**不回答**"违不违规、怎么处罚"。判定链路固定为：
   角色名 → 在 `08-人物-*.md` 查到阵营与特性 → 到对应 `06-阵营-*.md` 查友军/中立/敌对关系 → 套用第一至五章行为条款。
3. 阵营关系以 `06-阵营-*.md` 为准；本图鉴与规则库冲突时，规则库优先，并如实说明冲突。
4. 角色立绘、技能图标全部为图片，文字提取不到；本图鉴只含文字信息。

## 服务器名词（原文）

- 初始角色：回合开始时分配的角色
- 常规支援：随着时间流逝自然刷新的支援阵营
- 条件召唤：特定单位完成特定目标后会出现的阵营
- 伪装衣物：穿上后改变自身模型
- 防具：穿上后增加抗性
- 天赋：先天/后天带来的效果

获取方式在角色档案中出现的原文标记还有：`条件呼叫`、`事件角色`、`顾问呼叫`。原文未对这三种给出定义，被问到时如实说明"原文未定义，以游戏内实际刷新方式为准"。

- "可穿戴伪装衣物 / 可穿戴MTF阵营衣物 / 长的很像科研 / 长的像D级"直接关联 **3.6 防化服身份查验** 与 **4.8 人物模型问题**：外观不等于阵营，先用 3.6/4.8 判识别义务，再用 06-阵营关系判击杀性质。
- "携带X级权限卡 / 科研ID卡 / 医疗人员ID卡"关联第三章命令与查验场景（如 6.13 无权重令他人出示 ID，人事主管例外）。

- 生命/体力/冷却/距离等数值全部照抄原文，不换算不近似（同 R9）。

## 原文档缺陷与处理口径

1. **图片缺失**：角色立绘、技能图标均为图片，无法读取。被问"某个角色长什么样"时，回答"图鉴中该角色以图片展示，文字无法描述，以游戏内 F2 实际显示为准"。
2. **占位符**：原文部分 SCP 角色的技能栏为模板占位"点击输入文本"（如 SCP-096、SCP-542 等），已删除，代表"原文未写技能"。SCP-062-DE 的"生命：由选择的枪械而定"是原文如此。
3. **笔误**：原文存在 IUI/UIU、"黑旗/黑棋"混用等笔误，档案照抄原文，阵营归属以规则库为准。
4. **预留位**：NU-7-CBRN 核能化学排（对应 6.7）暂无角色档案；SKP 为 2026/10/17 新增的联动阵营（mio服联动），GRU-P 行动七组与 UIU 拦截者为 RHD 服务器联动阵营。
5. **能力描述≠规则**：角色的技能强度、护盾数值等是游戏机制，不是规则条文。被问"某技能算不算作弊/违规"时，依据第一、二章（作弊、OOC）判断，不依据本图鉴。
