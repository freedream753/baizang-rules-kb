## 事件判定规则（先读这段）

1. **先确认事件 + 阶段**：玩家说"仪式"必须先问清是**猩红召唤仪式**还是**欲肉教会仪式**；欲肉仪式必须确认**第一阶段还是第二阶段（大标提示）**。事件或阶段不明且影响结论时，先反问再回答。
2. **阶段识别标志**：欲肉第二阶段 = 大标提示；流星 = 回合进度条（右上角）变黄；紧急疏散三个时段 = 播报提示 → 阿尔法核弹启动中 → 阿尔法核弹已启动（5.1）。
3. **"武装单位"的范围**：指 09 阵营关系速查中"基金会系武装单位"11 个分支 + 其他持有武装的阵营单位；"未知单位"指原文未点名的其余阵营。范围存疑时引用原文原句。

## 事件一：猩红之子召唤仪式

**发起方（猩红之王之子）职责**（6.25）：

- 首要目标：完成猩红仪式，召唤你们的主；听从祭祀/助祭指挥完成仪式
- 核弹不影响主要任务流程，任务目标仍为完成召唤仪式
- 仪式期间可选择性前往阻止核弹，但被中止后**必须返回重新开启仪式**
- 可选择性忽视任务道路上无威胁的单位
- 卡祷告时间导致任务失败列为 OOC
- 任务失败（祭祀/助祭死亡且无法获得血书无法召唤）可以蹲死设施撤离大门或地表任意逃生地点
- ⚠ 禁止通过踩书/交互的行为判断猩红祈祷地点/GOC装甲（2.12）

**其他阵营职责**（2.6 + 管理确认）：

- **武装人员必管（管理确认）**：猩红之子的仪式开启时，**所有阵营的武装人员必须前往处理**（阻止/关闭），**GRU-P 的武装人员是唯一例外**（不必前往）。此裁定将 2.6"所有武装单位（GRU-P除外）必须前往关闭仪式"的同类义务扩展适用于猩红仪式；非武装人员无此义务，按各自任务/撤离规则行动
- 原文条款：核弹与猩红仪式**同时开启**时，所有人应更积极处理猩红仪式（离谁近先处理谁）（2.6）
- 基金会武装单位遇设施紧急状况必须前往阻止（6.2 通用义务）
- 欲肉教会：在猩红之子举行召唤仪式时应前往阻止（6.33）

## 事件二：欲肉教会仪式

**第一阶段**（2.6）：

- 其他阵营：继续执行自身任务
- 基金会武装单位：应搜寻地点做出反应

**第二阶段（大标提示）**（2.6）：

- 所有武装单位（**GRU-P 除外**）必须前往关闭仪式
- 所有未知单位**不可撤离设施**（GRU-P 除外）
- 必管义务主体为**武装人员**：持有武装的阵营人员均须前往关闭，GRU-P 是唯一例外；未武装人员无此义务，但仍受"未知单位不可撤离"约束（GRU-P 除外）

**发起方（欲肉教会）职责**（6.33）：

- 首要目标：全力前往锻炉处，取得◾◾的残体；听从牧羊人/先知指挥寻找锻炉并开启献祭
- 核弹不影响主要任务流程，任务目标仍为寻找锻炉为主
- 第二段献祭仪式失败后：剩余残党立即保护持有锻件的成员全力突围撤离设施（撤离时必须确认队伍内持有锻件者存活）
- 获取锻件后可选择撤离或继续祷告；持有锻件者必须提前通知同阵营自身目标
- ⚠ 可选择性忽视任务道路上无威胁的单位

**羔羊特殊规则**（6.33）：

- 任务：寻找轻收容散落的游戏机，成功后开启下一阶段（前往指定地点）
- 完成第二阶段献祭**立即死亡**，并成为欲肉教会成员转生
- 首要目标为隐藏身份完成任务；有把握击杀时允许暗杀（若因此死亡列 OOC）
- 禁止不执行任务、禁止主动置于已知可避免的威胁中
- ⚠ 羔羊**不属于**"间谍允许撤离"条款的间谍单位（2.6 明确排除羔羊）

## 事件三：阿尔法核弹（一般核弹事件）

> ⚠ 阿尔法核弹与"GOC 攻击组开核"**分开论**：本节应对职责 / 撤离资格 / 紧急疏散适用于**任意来源**的阿尔法核弹；GOC 攻击组开核的阵营前提与任务规则见本节末独立小节。

**应对职责**（2.6 / 6.2）：

- 核弹非法启动时：设施内基金会武装单位应**竭尽全力关闭**
- 核弹、仪式/欲肉开启时：地表驻守武装单位不持有下达设施的条件（无权限卡）应当**驻守通用撤离点直到最后30S**（2.6 与 6.2 双出处）

**核弹开启时的撤离资格**（2.6）：

| 阵营 | 能否撤离 | 原文条件 |
|---|---|---|
| 所有未知单位 | 可以撤离 | — |
| UIU特工组 | **不允许撤离** | 应当继续执行任务 |
| GOC | **不允许撤离** | 应当继续执行任务 |
| 蛇之手 | 有条件撤离 | 必须营救一个 SCP 才能撤离设施 |
| 间谍单位（不含羔羊、GOC间谍） | 有条件撤离 | 若拥有撤离设施的条件，允许撤离 |
| 猩红之子 | 不受影响 | 核弹不影响主要任务流程（6.25） |
| 欲肉教会 | 不受影响 | 核弹不影响主要任务流程（6.33） |

**紧急疏散时段**（5.1）：播报提示 → 启动中 → 已启动；开始后除 UIU特工组外所有阵营判任务失败，首要目标改为逃离设施，撤离途中可忽视敌对阵营。堵撤离点 / 能撤不撤细则见 5.1。

**GOC 攻击组开核（6.23，独立情形）**：

- 同回合互斥前提（管理确认）：GOC 攻击组与 GOC 大使不同场——本局有大使就没有攻击组，也就没有 GOC 引爆核弹事件；没有大使则可能出现攻击组（激流金属只与大使同场）
- 任务：入侵渗透基金会站点核弹井，引爆 Alpha/Omega 核弹完成无效化收容（6.23）
- 卡核弹时间导致任务失败列 OOC；可选择性忽视任务道路上无威胁的单位；任务失败后可蹲死大门或所有撤离点（6.23）
- 发现猩红之子/欲肉教会开始祷告可优先前往阻止再开启核弹（6.23）

## 事件四：流星

## 高频坑汇总

1. **"仪式"必须先问**：猩红仪式与欲肉仪式规则完全不同（关闭方/发起方/撤离资格都不同），不确认就回答必然出错。
2. **GRU-P 是仪式唯一例外**：猩红仪式"武装人员必管"时 GRU-P 的武装人员是唯一不必前往的（管理确认）；欲肉第二阶段"所有武装单位必须关闭"和"未知单位不可撤离"两条里 GRU-P 也都除外（2.6）。两类仪式的必管义务都只针对**武装人员**，非武装人员无此义务（欲肉为 2.6 原文，猩红为管理确认）。
3. **UIU 特工组特殊**：核弹开启唯一"不允许撤离继续执行任务"（2.6）；流星/紧急疏散唯一"不判任务失败"（5.1）；**流星触发时不适用紧急疏散规则、撤离优先级最高**（管理确认）。
4. **核弹分开论**：阿尔法核弹职责/撤离规则适用于任意来源的核弹；"GOC 攻击组开核"是独立情形（6.23），其存在前提是大使与攻击组互斥（管理确认），不要把一般核弹事件默认归因于 GOC 攻击组。
5. **蛇之手撤离门槛**：核弹开启时必须营救一个 SCP 才能撤离（2.6）。
6. **间谍撤离有排除项**：羔羊、GOC间谍不在"间谍允许撤离"范围内（2.6）。
7. **大标 = 欲肉第二阶段**：见到"大标提示"字样直接对应第二阶段条款（2.6）。
8. **猩红+核弹同时**：更积极处理猩红仪式，离谁近先处理谁（2.6）。
9. **两仪式互为天敌**：猩红要阻止锻造仪式、欲肉要阻止召唤仪式，被中止后猩红必须返回重开仪式（6.25 / 6.33）。
