## 回答前必须确认的三件事

1. **谁对谁**：双方阵营关系是友军、中立、敌对还是未知（见对应 `06-阵营-*.md` 末尾的阵营关系）。
   提到具体角色名（摔跤手、白棋皇后、九尾狐指挥官、各类间谍等）时，先经 `08-人物图鉴-总览.md` 把角色映射到阵营——间谍/派驻角色的实际阵营以人物档案标注为准，不是出生分组。
2. **在哪、何时**：所处区域、是否处于特殊事件及其阶段（紧急疏散/核弹/仪式）——事件别名先经 `10-术语别名表.md` 翻译，阶段识别标志与逐阵营职责查 `11-特殊事件速查.md`；同一行为在不同事件与阶段下结论不同。
3. **有没有明文处罚**：先查 `13-处罚速查.md`（明文数值 + 兜底口径）；没有明文就不得编造数值。

## 问题路由表（按问题类型定位文件）

- 问某行为"算不算违规 / 算不算 TK / 算不算堵" → 先查 `12-场景判定速查.md` 对应卡片，再回原文章节核对
- 问"怎么罚 / 会不会封 / 扣什么" → 只查 `13-处罚速查.md`，名单外一律答"规则未规定具体处罚，由管理裁量"
- 问两个阵营关系（友军/中立/敌对） → `09-阵营关系速查.md` 对应阵营卡片
- 问特殊事件（仪式/欲肉/核弹/流星）时某阵营该做什么 → `11-特殊事件速查.md` 对应阵营卡片
- 问条款原文、完整例外清单 → 对应 `01`~`05` 章原文件
- 问某阵营的任务、专属规则 → `06-阵营索引.md` 定位到 `06-阵营-*.md`
- 问某个角色是谁、属于哪个阵营 → `08-人物图鉴-总览.md` 定位到 `08-人物-*.md`
- 玩家用口语 / 别名提问 → 先经 `10-术语别名表.md` 翻译成标准名再检索
- 问规则改没改、某条还有没有效 → `07-第七章-规则版本改动记录.md`（判断条款时效的唯一依据）
- 问处罚不服、举报流程 → `01-第一章-服务器基本规则.md`（1.4 举报流程、1.8 处罚总表）
