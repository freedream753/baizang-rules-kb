# 处罚速查表（校验用 · 只收录文档明文）

> 用途：回答"怎么罚"时先查这里，只允许使用本表中的种类和数值。
> 表外行为一律回答"规则未规定具体处罚，由管理裁量"，不许自创。

## A. 明文数值

| 违规 | 处罚 | 出处 |
|---|---|---|
| 使用第三方辅助软件 | 永封（滤镜除外） | 1.3 |
| 为第三方软件或与本服无关的服务器发广告 | 禁言 100 天 | 1.5 |
| 乱用语音/文字频道（第 1 次） | 10 分钟双禁 + 1 个活跃警告（30 天可申请消除） | 1.8-3 |
| 乱用频道（第 2 次） | 24 小时双禁 + 5 个活跃警告 | 1.8-3 |
| 乱用频道（第 3 次） | 1 个低信誉 + 30 天双禁 + 10 个活跃警告 | 1.8-3 |
| 乱用频道（第 4 次） | 3 个低信誉 + ban 1 天 + 60 天双禁 + 20 个活跃警告 | 1.8-3 |
| 乱用频道（第 5 次） | 永久双禁 + 25 个活跃警告 | 1.8-3 |
| TK 或 RDM | 低信誉 x 把回合，或警告 x 次 | 1.8-1 |
| TK/RDM 且肇事逃逸 | 警告双倍，不发低信誉 | 1.8-1 |
| OOC | 警告 1 次 | 1.8-2 |
| OOC 且肇事逃逸 | 警告双倍 | 1.8-2 |
| 重大 OOC | 上限 1 警告 + n 低信誉 | 1.8-2 |
| 与敌对阵营合作撤离 | ban 24h + 扣除 1 级 | 2.2 |
| SCP-409 无防护使用致他人感染或死亡 | 尸体传染几人算几个警告 | 2.4-1 |
| 范围性武器导致多名队友死亡或感染 | 自第 3 名举报人起计 1 次 TK，其后每多 1 人 +1 次 TK | 4.2-2 |
| 社区内煽动舆论、散布谣言、侮辱诽谤 | 从严处罚（未给数值） | 1.4-5 |

## B. 写明"禁止"但未给数值（→ 兜底口径）

回答模板：**"规则禁止该行为，未规定具体处罚；归入【X 类】由管理裁量，可参照的明文上限是……"**

- 2.8 堵出生点（禁止提前破门、蹲守、未读完复活动画即杀人）
- 2.11 死亡记忆
- 2.12 多数利用 BUG 的条目
- 2.3 损害同阵营利益
- 3.1 广播命令违规（违令不算 OOC，但他人有权处决）
- 3.4 不合理命令（本身不生效，不处罚）
- 4.3 信息差、4.4 自卫反击、4.6 RDM 多数情形（按 1.8-1 体系处理）
- 5.1 堵撤离点、能撤不撤（原文只说"视作 OOC / 可能被视作"）
- 6.x 各阵营任务违规（多数导回 OOC 体系）
- 7.x 已删除的条款不得再引用

## C. 减责 / 免责 / 加重

| 情形 | 效果 | 出处 |
|---|---|---|
| 被 TK/RDM 方选择原谅 | 可免于惩罚 | 1.8-1 |
| 频道违规被举报人谅解 | 可免除（管理发现的除外） | 1.8-3 |
| 不可抗力（卡顿等） | 被害人 + 现场管理可决定以低信誉替换警告 | 1.8-4 |
| 肇事逃逸 | 警告双倍、不发低信誉 | 1.8-1、1.8-2 |
| 特殊模型误判 | 杀对不算猜杀；杀错算 TK，不是 RDM | 4.8-4 |
| 被欺骗促使 TK | 被欺骗者不负责，怂恿者负责 | 4.3 |
| 指挥官错误播报导致 TK | 由指挥官承担 | 2.8 对讲机 第 4 条 |
| 在规则上恶意误导他人 | 误导者与违规者共同承担 | 1.7-2 |
| 出于不可抗力违反 OOC 准则 | 被害人 + 现场管理裁量替换处罚 | 1.8-4 |

## D. 证据要求

## E. 不得作为处罚依据的条款

- 3.7 持有（保有枪支）命令：原文标注"暂不生效"
- 2.9 停机坪/平台拦截例外：标注"实装掩体后删除"，现行有效，但不要用于预测未来版本
- 2026/10/23 已删除的"通用撤离点可以随意被堵"：不得再引用

## F. 已知文档矛盾（回答时并列，不替文档取舍）

1. **6.13 科研部门**：阵营关系写"中立：其他阵营都是"，同时写"敌对：全球超自然联盟 猩红之王之子"。
2. **6.19 SCP-999**：文档写"对 SCP 阵营敌对"，同时多个基金会阵营把 SCP-999 列为友军。
3. **6.23/6.24 名称为原文笔误**："全球超级燃联盟""全球超不燃联盟"均指 GOC，引用时保留原名可加注。
4. **6.14 与 6.16**：混沌分裂者"首要目标"重复出现，按各自阵营分别适用，不要合并。
